# AI Agent & MCP 智能体大作业项目

## 1. 需求描述
本项目构建了一个基于 Python 与 Model Context Protocol (MCP) 框架的智能办公/科研助手，具备自然语言对话（能说）与自动化工具调用（会做）能力。

## 2. 业务流描述
1. 用户在客户端输入自然语言指令。
2. 大模型解析意图，判断是否需要调用外部工具。
3. 通过 MCP 协议调用对应的服务端工具（如文件处理、计算或数据查询）。
4. 将工具执行结果结合大模型整理后返回给用户。

## 3. 快速运行指南
1. 安装依赖：`pip install -r requirements.txt`
2. 运行服务端与客户端。
