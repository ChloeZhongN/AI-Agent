## 一、需求描述

本项目实现一个面向日常办公和学习场景的智能助手。用户可以用自然语言提问；当请求涉及算术计算或读取项目内文本文件时，智能体会判断并调用相应工具，再根据工具结果组织回答。

项目提供两个本地工具：基础算术计算器和项目目录内的文本文件读取器。计算器只接受数字、括号和基础算术运算符；文件读取限定在项目目录中，并限制单个文件大小，避免工具获得不必要的本机访问范围。

## 二、业务流程

1. 用户在网页聊天界面输入任务，也可以使用浏览器语音输入。
2. 前端通过 FastAPI 的流式接口提交文本和会话 ID。
3. 大模型根据上下文判断直接回答，或请求调用计算器、文件读取工具。
4. 后端执行工具，将调用参数和执行结果通过 SSE 事件发给前端。
5. 大模型结合工具结果生成答复；前端展示答复和工具调用过程，并可朗读内容。

## 三、实现说明

- **前端**：原生 HTML、CSS 和 JavaScript，提供聊天输入、会话列表、工具执行记录、深浅色主题及语音输入/朗读。
- **接口层**：FastAPI 提供对话、SSE 流式响应、会话管理和健康检查接口，并托管前端静态资源。
- **智能体**：通过 OpenAI 兼容的通义千问接口进行多轮对话和函数工具调用；服务端按会话 ID 暂存上下文。
- **工具层**：Python 函数实现安全算术解析和受限文件读取，按工具名分发执行。
- **密钥配置**：模型密钥通过 `DASHSCOPE_API_KEY` 环境变量提供。不要把密钥写入代码或提交到 Git。

本版本使用模型函数调用和本地 Python 工具注册表来完成调度，属于 MCP 风格的工具调用流程，尚未建立独立 MCP 协议服务端。如课程验收要求实际 MCP 协议，需要在此处补充协议服务端和客户端连接说明。

## 四、使用示例

在项目根目录安装依赖并设置模型密钥：

```powershell
pip install -r requirements.txt
$env:DASHSCOPE_API_KEY="你的 API Key"
python frontend/app.py
```

打开 <http://127.0.0.1:8000> 后可以尝试：

1. **计算**：输入“帮我计算 (1024 × 8 + 256) ÷ 16”，观察工具调用参数、计算结果和最终解释。
2. **读取文件**：输入“读取 README.md 并总结项目内容”，观察智能体读取项目文件后生成总结。
3. **多轮对话**：先问“读取 requirements.txt”，再问“刚才读取的依赖里有哪些服务端组件？”，观察上下文是否保留。
4. **语音交互**：在支持 Web Speech API 的浏览器中授权麦克风后使用语音输入，并开启回复朗读。
