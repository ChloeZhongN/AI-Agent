AI Agent 前端功能测试方案与演示录制脚本
=======================================

1. 测试目标
-----------
验证用户通过网页界面进行自然语言交互、触发 Agent 工具执行、观察执行过程、
管理会话，以及使用图片和语音功能时，前后端连接和页面交互是否正常。
本方案同时提供演示视频的录制步骤、讲解顺序和验收清单。

2. 测试范围
-----------
包括：
- 首屏、服务状态、工具列表、输入框和错误提示。
- 自然语言对话、Enter 发送、Shift+Enter 换行、流式状态和工具调用轨迹。
- 计算、文件读写、SQLite 待办和图片上传/识别。
- 会话新建、切换、历史记录、删除和刷新恢复。
- 主题切换、语音输入、自动朗读、单条朗读和复制回复。
- 桌面与移动视口布局、后端离线和输入异常时的表现。

不包括：
- 对大模型回答质量、模型供应商可用性及 API 额度进行基准测试。
- 浏览器以外的 MCP 服务部署和数据库性能测试。
- 自动化生成真实语音录音。语音能力需在目标浏览器和麦克风权限下人工确认。

3. 测试环境与准备
-----------------
1) 在项目根目录安装 requirements.txt 中的依赖。
2) 设置有效的 DASHSCOPE_API_KEY、DASHSCOPE_BASE_URL 和 DASHSCOPE_MODEL。
   禁止在录屏、终端共享或视频画面中展示密钥。
3) 在项目根目录运行：
       python frontend/app.py --no-browser
4) 浏览器访问：
       http://127.0.0.1:8000
5) 使用当前版本 Chrome 或 Edge；语音输入需允许麦克风，语音朗读需允许网页播放声音。
6) 检查侧栏显示“Agent 在线”，工具数量为 5；若端口 8000 已被占用，先确认占用
   服务属于本项目后再复用，或选择其他端口运行。不要结束不明来源的进程。
7) 选择可删除的演示数据。待办任务使用“演示-”前缀，演示文件写在项目内的
   tests/demo-output/ 目录；结束后从 UI 删除演示待办，并人工清理演示文件。
8) 记录浏览器名称/版本、操作系统、测试日期、后端健康状态和有效 API 配置情况，
   但不记录 API 密钥。

4. 测试级别与判定
-----------------
P0：关键使用路径。首屏和服务状态、对话发送与回复、工具执行结果可见、
图片上传、会话基本管理。P0 全部通过方可录制正式演示。
P1：语音输入/朗读、复制、主题持久化、移动端布局、异常恢复。
P2：不同分辨率和浏览器的兼容性抽查。

单项判定：
- 通过：实际结果符合预期，页面无未处理错误，操作可继续。
- 失败：页面崩溃、交互无响应、工具结果错误/不可见、数据丢失，或错误状态未提示。
- 阻塞：测试依赖无法满足，例如模型 API 不可用、麦克风权限被禁用；记录原因，不计为通过。
- 不适用：该环境明确不支持相关能力，例如浏览器没有 Web Speech API。

6. 演示视频录制脚本（约 2–3 分钟）
----------------------------------
建议工具：OBS Studio（可单独录制浏览器窗口和麦克风），或 Windows Xbox Game Bar
（Win+Alt+R；以本机系统设置为准）。录制前关闭无关窗口和通知，浏览器缩放设为 100%，
窗口使用 1920x1080 或 1600x900；输出 MP4、30 fps。开启麦克风讲解时先试听音量。

0:00–0:15 片头/项目介绍
展示首页全貌、项目名称、“能说·会做”、Agent 在线状态及可用工具数。
旁白示例：“这是一个可以自然语言交流，并能调用本地工具执行任务的智能助手。”

0:15–0:40 自然语言对话
发送“你好，请简要介绍你能做什么”。
展示用户消息、思考过程和自然语言回复。

0:40–1:10 计算工具
发送“请计算 (1024 * 8 + 256) / 16”。
展示工具名称、参数、返回值 528，以及助手的总结回答。

1:10–1:35 文件处理
发送“读取 README.md 并总结项目功能”。
展示文件读取工具轨迹与基于文档生成的摘要；避免长时间滚动敏感内容。

1:35–1:55 待办管理
新增一个以“演示-”开头的待办并查看列表，演示完成/删除，避免留下演示数据。

1:55–2:15 图片识别（如演示环境可用）
上传一张无隐私内容的样例图片，展示预览、发送问题、工具调用和识别结果。

2:15–2:35 会话和界面偏好
展示会话列表/切换、新建会话、深浅色切换；如时间允许展示移动视口。

2:35–2:50 收尾
简短总结：自然语言对话、实时工具调用可视化、本地任务执行。
停止录制后检查视频能否播放、画面清晰、语音完整，并确认没有显示 API 密钥、个人通知、
浏览器地址栏以外的敏感数据或真实私人文件内容。
