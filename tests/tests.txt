AI Agent 项目测试用例
====================

测试范围
--------
根据项目需求，验证智能体能理解并处理语言交互相关的服务端对话流程，以及可执行的文件、
计算、图片识别和待办管理操作。模型交互使用模拟响应，不访问真实模型服务；所有文件和
SQLite 测试数据均写入临时目录，不依赖或修改项目已有数据。

用例列表
--------
TC-01 计算器支持四则运算和括号
输入表达式：(1024 * 8 + 256) / 16
预期：计算结果为 528。

TC-02 计算器拒绝不支持的表达式
输入包含 Python 导入和命令调用的表达式。
预期：返回计算错误，不执行表达式。

TC-03 读取 UTF-8 本地文件
在临时工作区创建含中文的文本文件并读取。
预期：返回成功提示和原文件内容。

TC-04 读取不存在的文件
读取临时工作区中不存在的文件。
预期：返回明确的找不到文件提示。

TC-05 写入嵌套目录中的 UTF-8 文本文件
写入带中文的 Markdown 内容。
预期：创建所需目录，文件内容与输入完全一致。

TC-06 拒绝写入工作区之外
通过相对路径尝试写入工作区父目录。
预期：拒绝写入并返回安全限制提示，目标文件不产生。

TC-07 待办事项新增、查询、完成、删除
依次新增待办、查看清单、标记完成、再次查询并删除。
预期：任务内容和状态正确展示；删除后清单为空。

TC-08 拒绝空白待办事项
新增内容仅包含空格的待办。
预期：返回 task 不能为空的错误提示。

TC-09 图片路径不存在
分析临时工作区中不存在的图片路径。
预期：返回明确的找不到图片提示，不调用模型。

TC-10 图片识别请求参数
在临时目录提供图片数据并模拟视觉模型返回。
预期：请求包含图片数据 URL 和用户问题，工具返回模拟识别结果。

TC-11 工具分发正常
通过 execute_tool 调用计算器。
预期：工具被正确分发并返回计算结果。

TC-12 未知工具名称
通过 execute_tool 调用未注册名称。
预期：返回明确的未知工具错误。

TC-13 智能体工具调用与自然语言回复
模拟模型先请求计算器，再返回自然语言回答。
预期：执行计算、记录工具结果及会话历史，并按顺序发出状态、工具调用、
工具结果和最终回答事件。

TC-14 空白对话输入
向智能体提交仅含空格的输入。
预期：抛出 AgentError，且不请求模型。

TC-15 模型服务异常
模拟模型服务调用失败。
预期：将底层异常转换为可供服务层处理的 AgentError。

TC-16 自然语言多轮对话
模拟模型连续返回中文自然语言回答，使用同一 session_id 发送两轮消息。
预期：返回可读回复、不调用工具，第二轮模型上下文和会话历史包含第一轮对话。

TC-17 对话 API 转发自然语言任务
向 chat API 处理函数提交自然语言计算请求，并模拟智能体完成计算。
预期：API 将用户消息和会话 ID 传给智能体，并返回回复、会话 ID 和工具调用记录。

TC-18 健康检查 API
调用健康检查接口处理函数。
预期：返回正常状态、模型名称和已注册的工具名称。

TC-19 图片上传与后续工具路径
通过上传接口处理函数提交 PNG 图片内容。
预期：生成随机文件名并保存图片字节，响应返回可供图片识别工具使用的 uploads/ 相对路径和访问 URL。

TC-20 拒绝不支持的上传文件类型
上传 .txt 文件。
预期：接口返回 HTTP 400，且不读取上传内容。

TC-21 文件处理工具端到端往返
先通过工具分发器写入包含中文的日程 Markdown 文件，再调用读取工具。
预期：读取结果包含完整原始文件内容。

TC-22 对话 API 请求校验
通过 ASGI HTTP 请求向 /api/chat 提交空消息。
预期：接口返回 HTTP 422，并指出 message 字段校验失败。

运行方式
--------
在项目根目录执行：
    python -m unittest discover -s tests -p "test_*.py" -v

通过标准
--------
所有自动化用例均通过；测试不需要有效的大模型密钥、外网访问或运行中的服务。
